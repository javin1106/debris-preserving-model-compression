## VSCP augmentation (`utils/vscp.py`)

Called in `train.py` on every training batch after loader augmentation. With batch size B it builds `B // 2` new images: for i < B//2, every **labelled** pixel of image i + B//2 (all 11 bands and the label) is copied onto image i. Unlabelled pixels of the source are not copied, so the target image keeps its own bands and labels there. The new images are appended to the batch (B = 5 → 7 images per step); the originals are kept unchanged.

Check on a fixed batch of 5 training items (seed 0): 5 in → 2 added.

| target ← source | source labelled px | labels changed px | pasted labels = source | pasted bands = source | other px unchanged | labelled px before → after |
|---|---|---|---|---|---|---|
| 0 ← 2 | 382 | 382 | True | True | True | 40 → 422 |
| 1 ← 3 | 52 | 52 | True | True | True | 1,498 → 1,550 |
